# Атлас света R14.2 — единая сборка VK + OK

Это готовые файлы HTML5-игры «Атлас света» после интеграционных исправлений и оптимизации обработки нажатий. Распакуйте содержимое архива в **корень** существующего статического хостинга/GitHub Pages. `index.html`, `assets/` и остальные файлы должны остаться в тех же относительных путях. Менять адреса скриптов и структуру директорий не нужно.

## Для двух площадок

- VK Mini Apps запускает `VKWebAppInit`, локальное/облачное сохранение, rewarded и interstitial SDK по его возможностям.
- Одноклассники обнаруживаются через параметр `vk_client=ok`. Для новых VK Mini Apps отдельный старый `FAPI` не используется; неподдерживаемая команда `VKWebAppSetSwipeSettings` в ОК не вызывается.
- По официальной публичной таблице OK объявления в VK Bridge задокументированы на Android. В этой сборке OK iOS/Web не предлагают неработающую rewarded-рекламу; поддержка на реальных клиентах требует подтверждения. В первые 30 сек любой новой OK-сессии реклама не запускается.
- Для публикации в ОК включите соответствующую опцию в панели VK, привяжите аккаунт разработчика ОК, проверьте приложение **в обеих сетях** и отдельно подайте на модерацию. Официальная инструкция: https://apiok.ru/apps/fast.

## Что сохранено

180 уровней, анимации переливания и активации кристалла, магазин за игровую валюту, лаборатория, экономика, подсказки, звуки, R14-визуал, VK Bridge R14.1, обратная совместимость сохранений. Формат прогресса не менялся. При выборе бутылки теперь не создаётся заново всё поле, поэтому отклик быстрее без снижения графики.
