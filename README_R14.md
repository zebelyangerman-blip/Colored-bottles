# Атлас света — R14 Luminous Observatory

Релиз: 12.10.2026. Содержимое папки с `index.html` является готовой автономной HTML5-игрой для раздачи статических файлов (при поддержке платформенного SDK и условий вашей публикации).

### Основные отличия
- Новые объёмные стеклянные сосуды и контрастные рецепты без геометрического растяжения 120x220 SVG.
- Постоянные связи всех сосудов с кристаллом и анимированная вспышка энергии при сборке рецепта.
- Визуальная прогрессия центрального кристалла по числу собранных сосудов.
- Усиленные контрасты, объём кнопок, декоративные отблески, монета PNG вместо схематической пиктограммы в интерфейсе.
- Исправлено случайное прерывание переливаний мобильным ResizeObserver.
- Для коротких портретных экранов — прокрутка вместо наложения бутылок.
- При победе окно показывается с задержкой, чтобы игрок успел увидеть активацию.

### Проверка
- `node tools/check-levels.cjs`: 180/180 корректных сертификатов прохождения, ошибок 0.
- Chromium desktop 1440x900 и mobile 390x844: первый уровень пройден 8 действиями через настоящие игровые события, победа и активация работают. Проверены сцены 76, 81, 141, 161 и 180.
- Изображения и интерфейс проверены на 320x568 (с прокруткой), 390x844, 768x1024, 844x390, 1024x768, 1440x900.
- Не тестировались реальная реклама, загрузка облачных сохранений VK/Яндекс и аппаратная производительность телефонов. Проверка Chromium на ПК не равна физическому устройству.

### Совместимость
Основные игровые данные, лимиты ходов, правила, экономика и формат сохранений **не менялись**.
Новые библиотеки и сетевые зависимости не требуются. Авторские лицензии — `LICENSES.txt`.

### Развертывание
Разместить `index.html`, `assets/` и прочие файлы текущей папки вместе в корне статического сайта. При обновлении GitHub-репозитория заменить одноимённые файлы и добавить `assets/css/r14-luminous.css`. Не удалять существующие `assets/`.

Технический баланс: `BALANCE_REPORT_R14.md`, таблица всех 180 уровней: `ATLAS_LIGHT_R14_ALL_180_LEVELS.csv`.
