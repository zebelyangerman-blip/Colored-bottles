# Атлас света — VK Mini Apps R14.1

Это обновлённая игра из релиза R14 с доработками для запуска в VK Mini Apps. В игру входят все 180 уровней, графика R14, музыка, сохранения, магазин за игровые монеты, рекламные подсказки и новая обработка возврата.

## Что изменено относительно R14

- **Bridge:** основная и резервная загрузка официального SDK v2.15.11, инициализация VK без изменения правил игры.
- **Навигация:** история и переключение настроек свайпа VK, корректное возвращение из внутренних разделов.
- **Rewarded:** проверка доступности рекламы непосредственно перед показом, награда только после успеха.
- **Cloud Storage:** сохраняет прежний формат маленьких записей; большие записи автоматически делятся на блоки с переключением A/B, чтобы старое облако не терялось при неудачной записи.
- **Cache busting:** `app.js?v=14.1.0` в `index.html`.

## Публикация на GitHub Pages

1. Распаковать содержимое ZIP. В корне находятся `index.html` и каталог `assets/`.
2. В репозитории заменить одноимённые файлы, включая **оба** `index.html` и `assets/js/app.js`; добавить остальные ассеты, если их нет. Не заменять один лишь `index.html`.
3. Проверить загрузку HTTPS-страницы на телефоне и ПК.
4. В настройках приложения VK проверить URL для мобильной и десктопной платформ и остальные обязательные поля.

При обновлении уже работающего GitHub Pages используются тот же URL и существующий ID VK Mini Apps — создавать новое приложение не требуется.

## При использовании хостинга VK

Для загрузки через `vk-miniapps-deploy` документация VK предусматривает `vk-hosting-config.json` с действительным **числовым** `app_id`, `static_path` и маршрутами `endpoints` для `mobile`, `mvk`, `web`. В этой поставке такой файл намеренно **не создан с фиктивным ID**, поскольку реальный идентификатор и выбранный способ хостинга не предоставлены. Конфигурация настраивается в кабинете и под ваш процесс развертывания, а не изобретается автоматически.

См.: <https://github.com/VKCOM/vk-mini-apps-course-frontend>.

## Результаты и оговорки

- `node tools/check-levels.cjs` — **180/180** уровней решаемы по правилам, сертификаты пройдены.
- Проверены Chromium 1280×800, 390×844 и 320×568, экранные переходы, модальные правила, браузерный `Back`.
- Проверено имитатором Bridge: инициализация и навигационные события, выдача/отказ в рекламной подсказке, большие облачные сохранения с имитацией сбоя сети.
- **Не проверены на реальной платформе:** показ рекламы VK, загрузка CDN в WebView VK, работа облака между настоящими аккаунтами/устройствами, фактический прохождение модерации.
- **Не подтверждены юридически:** права на все ранее переданные изображения/музыкальные материалы. См. `LICENSES.txt`.
